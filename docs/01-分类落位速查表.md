# 🗂️ 分类落位速查表（第 1 号文件）

> 拿到一条新信息，按下面**从上往下**判断，命中即停。
> 配套 [[【第0号】知识库宪法]]

---

## 第一步：先问「这是什么形态」

```
1. 是灵光一闪 / 外部抄来的素材，我还没消化？
   → 02_灵感文件/          （丢进去就行，不用管分类）

2. 是马上要处理的零碎东西，还没想好归属？
   → 01_收件箱/            （每周清空）

3. 是「某个人/东西/方法 是什么」的知识点？
   → 05_知识库/概念笔记/    命名：概念-XXX

4. 是「我遇到了 X 问题，怎么解决的」？
   → 05_知识库/问题排查/    命名：排查-XXX

5. 是「我做某类事情总结出的规律」？
   → 05_知识库/经验教训/    命名：经验-XXX

6. 是「做某件事的标准步骤」？
   → 05_知识库/流程SOP/     命名：SOP-XXX

7. 是一份「名单 / 花名册 / 清单」类的参考数据（人员、料号、客户…）？
   → 03_领域/<对应领域>/    命名：名单-XXX

8. 是一个有开始有结束的任务？
   → 04_项目/              命名：项目-XXX

9. 是某个长期主题下的内容（上面都不合适）？
   → 03_领域/<对应领域>/

10. 是今天的流水记录？
    → 07_日记/YYYY-MM-DD

11. 是**模板/样张/参考样板**（被取代标注、体检报告、格式模板等）？
    → 00_系统/02_模板/    命名：直接用功能名（被取代标注.md、体检报告.md）

12. 是**被废止 / 被新版取代的旧笔记**（保留供回溯）？
    → 留在原位，顶部加「⛔ 已被 新笔记 取代（YYYY-MM-DD）」（不删不归档；模板见 `00_系统/02_模板/被取代标注.md`）

13. 是**参考资料 / 速查表 / 对照表**（不写长内容，纯查阅）？
    → 落 `03_领域/<领域>/` 或 `06_索引MOC/`，命名 `参考-XXX`（例：`参考-Minitab会话命令`、`参考-共享盘资料源地图`）
```

---

## 第二步：判断属于哪个「领域」

`03_领域` 目前四个分区，判断标准：

| 领域 | 装什么 | 举例 |
|---|---|---|
| `工作方法` | 做事的方法论、思维模型、效率 | GTD、复盘、优先级矩阵 |
| `工具与技术` | 软件、脚本、技术原理 | Obsidian、Python、Excel 技巧 |
| `业务与行业` | 具体行业/公司业务知识 | 材料工艺、客诉流程、申报政策 |
| `软技能与沟通` | 和人打交道 | 跨部门沟通、向上管理、汇报 |

**都不属于上述 → 放 `03_领域/其他/`**（需要时再新建分区，不轻易加）。

---

## 第三步：判断「项目 vs 领域」

| 判断 | 归类 |
|---|---|
| 有明确完成标志（交付了就结束） | 项目 |
| 会一直持续关注 | 领域 |
| 说不好 | 先放 `04_项目`，结项时再决定去留 |

---

## 常见误区对照表

| ❌ 错误做法 | ✅ 正确做法 |
|---|---|
| 一篇文章整个复制进来 | 只提取对我有用的部分 + 我的理解 |
| 同一个知识点在两个文件夹各存一份 | 只存一处，另一处用 `[[]]` 链接 |
| 文件名写「笔记1」「新建文档」 | 用命名规范 `概念-XXX` |
| 灵感文件里堆着不处理 | 定期分析 → 沉淀 → 移入 `_已沉淀` |
| 笔记之间没有链接 | 每条笔记至少挂一个 MOC，正文用双链 |
| 直接把好文章链接存在收件箱 | 提取要点写成原子笔记，原文链接放 frontmatter 的 `source` |

## 命名规范速查

| 类型 | 格式 | 好例子 | 坏例子 |
|---|---|---|---|
| 概念 | `概念-XXX` | `概念-双链笔记法` | `双链` |
| 排查 | `排查-XXX` | `排查-剪贴板被占用` | `电脑问题` |
| 经验 | `经验-XXX` | `经验-先对齐目标再动手` | `心得` |
| SOP | `SOP-XXX` | `SOP-周报写法` | `流程` |
| 项目 | `项目-XXX` | `项目-知识库搭建` | `KMS` |
| 名单 | `名单-XXX` | `名单-某项目人员-2601` | `在职表` |
| 灵感 | `YYYYMMDD-描述` | `20261008-PARA方法` | `灵感1` |
| MOC | `MOC-XXX` | `MOC-项目管理` | `索引` |
| 日记 | `YYYY-MM-DD` | `2026-10-08` | `今天` |
