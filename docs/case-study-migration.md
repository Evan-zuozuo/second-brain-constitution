**方法论要点**：
- **先立骨架后迁数据**：宪法和目录结构先落地，存量数据按映射表并入，避免「边迁边定规则」的静默分叉。
- **集合一致性闸门**：迁移前后比**文件名集合**（不是文件数），数量对但内容被顶替 = 静默丢失。
- **PII 实时检测**：迁移过程中跑敏感信息扫描，命中即隔离，不等事后人工翻。
