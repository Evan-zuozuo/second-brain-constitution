## 四、红线（gates）

- 打标必带：置信度 A/B/C/D + 时效 P/L/M/S/E；C/D 不作决策唯一依据
- frontmatter 八件套：title/type/domain/status/created/updated/source/tags
- 敏感区与原料区**永不镜像、永不外发**
- 云端写入只许进指定分区；其他库只读
- **AI 永不删除文件**——要删的先移「待删除暂存区」，由笔者最终处置
- 业务数据 A/B/C/D 分级：A 直接入 / B 整理后入（标 snapshot_date）/ C 只入指针 / D 不入
- md 文件 UTF-8 **无 BOM**；.ps1 脚本 **带 BOM**（PowerShell 5.1 中文刚需）
- 矛盾走 `[CONFLICT]`→裁决→`[RESOLVED]`，不静默改写
